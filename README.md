A library of ideas and rules for automating insurance claims.
# SwiftClaim: The Auto-Pilot for Insurance 🚗💨

### What is this?
This is a project that shows how to process insurance claims without any humans involved! We call this **Straight Through Processing (STP)**.

### How it works:
1. The customer sends the claim details.
2. Our "Logic Robot" checks the rules.
3. If everything is perfect, the claim is paid instantly!
